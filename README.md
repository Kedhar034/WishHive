# WishHive 🐝

> **Organize your dreams, connect with friends, and make wishes come true.**

WishHive is a beautiful, social wish-listing application built with Flutter. It helps users organize their desires into "Hives" (collections), share them with friends, and mark them as fulfilled. With a focus on privacy, social interaction, and a premium user experience, WishHive turns chaotic wishlists into a shared journey.

![App Banner](https://via.placeholder.com/1200x600?text=WishHive+Banner)

## ✨ Key Features

### 🍯 Organize with Hives
-   Create custom **Hives** to categorize your wishes (e.g., "Tech Gadgets", "Books to Read", "Birthday 2026").
-   Add rich details: Images, links, costs, and notes.
-   **Privacy Controls**: Set Hives as **Public**, **Friends Only**, or **Private**.

### 🤝 Social Connection
-   **Friend System**: Search for users by username, send requests, and build your circle.
-   **Real-time Notifications**: Get instantly notified of new friend requests with in-app badges.
-   **Friend Feed**: See what your friends are wishing for and stay inspired.

### ✅ Wish Fulfillment
-   **Mark as Fulfilled**: Track what you've bought or received.
-   **Gift & Claim**: Friends can view your shared hives and mark wishes as "Fulfilled by [Name]" – perfect for gifting!
-   **Owner Override**: You always have full control to update or reset fulfillment status.

### 🛍️ Marketplace (Coming Soon)
-   Explore a curated feed of trending items.
-   Smart recommendations based on your Hives.

## 🛠️ Tech Stack

-   **Frontend**: Flutter (Dart)
-   **Backend**: Node.js & Express (Custom API)
-   **Database**: Firebase Firestore (Real-time NoSQL)
-   **Auth**: Firebase Authentication
-   **Storage**: Firebase Storage (Image hosting)
-   **State Management**: Flutter Riverpod

## 🚀 Getting Started

### Prerequisites
-   Flutter SDK installed ([Guide](https://flutter.dev/docs/get-started/install))
-   Firebase configured for your project

### Installation

1.  **Clone the repository**
    ```bash
    git clone https://github.com/Kedhar034/WishHive.git
    cd WishHive
    ```

2.  **Install Dependencies**
    ```bash
    cd flutter_application_1
    flutter pub get
    ```

3.  **Run the App**
    ```bash
    flutter run
    ```
